Fonctions principales

Tout ce qui rapproche
l’idée de l’écran.

Flutter Go pilote le SDK Flutter officiel — aucune surcouche opaque, aucun fork.

01

Hot Reload automatique

Chaque sauvegarde de lib/ recharge instantanément l’app sur l’appareil. Sur plusieurs appareils à la fois.

02

Zéro câble

fluttergo wifi bascule le téléphone en mode sans fil. Android 11+ s’appaire même sans câble.

03

Partage par QR code

fluttergo share compile l’APK et affiche un QR : le téléphone scanne, télécharge, installe.

04

Équipe sur un appareil

fluttergo host / join : tout le monde itère sur le même téléphone, en temps réel.

05

iPhone depuis Windows

fluttergo attach — après une installation initiale depuis macOS, itérez depuis Windows.

06

Diagnostic honnête

fluttergo doctor détecte Flutter, ADB, SDK Android, licences et dit exactement ce qui manque.

FAQ

Questions honnêtes.

Est-ce gratuit ?

Oui : Flutter Go est open source (MIT) et restera gratuit pour les fonctions CLI. Un futur abonnement « Pro » (outils d’équipe avancés) est en préparation, sans date d’engagement.

Est-ce un fork de Flutter ?

Non. Flutter Go pilote le SDK Flutter officiel (flutter run --machine). Il ne remplace ni Flutter, ni Android Studio, ni Xcode.

iPhone depuis Windows ?

Après une installation initiale depuis macOS (contrainte Apple), oui : fluttergo attach donne le Hot Reload depuis Windows au quotidien.

Où sont les sources ?

Le dépôt de développement est privé pendant la phase pré-lancement. La licence MIT sera honorée : les sources publiques seront publiées avec la v1.0.
